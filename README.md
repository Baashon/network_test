# Тест: настройки сети

Внутренний тест для сотрудников на знание настроек сети.

## Что внутри

- Выбор должности (7 вариантов): общий тест + 6 тестов по категориям инженеров/менеджеров
- По 30+ вопросов в каждом наборе
- Таймер на 30 минут
- Результаты сотрудников сохраняются автоматически и видны всем, кто открыл сайт (кнопка «Результаты сотрудников»)

## Как открыть

Файл `index.html` открывается прямо в браузере — можно скачать и открыть локально,
либо разместить через GitHub Pages (см. ниже) и разослать сотрудникам ссылку.

## Публикация через GitHub Pages

1. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`
2. Сайт появится по адресу `https://<username>.github.io/<repo-name>/`
